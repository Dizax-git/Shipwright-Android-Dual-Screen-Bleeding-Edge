First release. SoH 9.3.1 for the AYN Thor with a rando tracker on the bottom screen: items, hint map, and the checks you can do right now.

**Before installing:** uninstall any other SoH build that uses `com.dishii.soh` (Darkaxt's port for example), this APK is signed with a different key. Your `SOH` folder stays, but back it up. Then install the APK and pick your ROM.

On the Thor, set Autolock to the top screen in the AYN settings.

Everything else is in the [README](https://github.com/Dizax-git/Shipwright-Android-Dual-Screen-Bleeding-Edge#readme). The `.sha256` file is the checksum of the APK.
